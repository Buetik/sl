# Workflow: контроль качества и приёмка

1. Чек-лист этапа создаётся **при планировании** (до работ) — `project/quality-checklists/stage-XX-*.md`.
2. Пользователь выполняет проверки по чек-листу: замеры (числа), фото (с рулеткой/правилом в кадре,
   боковой свет для поверхностей), протоколы специалистов (электрика, опрессовка).
3. `quality-controller` оценивает каждый пункт: соответствует / не соответствует / нет данных.
   «Нет данных» по скрытым работам = не принято.
4. Вердикт:
   - **ПРИНЯТЬ** — все пункты соответствуют.
   - **ПРИНЯТЬ С ЗАМЕЧАНИЯМИ** — только замечания, не влияющие на последующие этапы; задачи на исправление.
   - **НЕ ПРИНИМАТЬ** — есть критичный дефект; указать «СТОП» и способ исправления.
5. Пользователь подтверждает → `reno.py set-stage N accepted --confirmed-by-user --checklist <путь>`.
6. Дефекты и выводы → `project/log/journal.md` (раздел «Ошибки и уроки» — чтобы не повторять).
