# Workflow: сопровождение выполнения работ

1. **Перед началом дня:** `/next` → список задач; проверить ворота; наличие материалов и инструментов;
   условия (температура/влажность в помещении по техкартам); СИЗ.
2. **Перед операцией:** открыть инструкцию из `project/instructions/` (или `/instruction`). Для новой
   операции — пробная захватка на неответственном месте.
3. **Во время:** контроль по ходу (маяки, правило, нивелир). Отклонение от инструкции или
   непредвиденное (трещины, мокрые пятна, старая проводка в стене, пустоты) → остановиться,
   сфотографировать, `/log` — агент оценит.
4. **Скрытые работы (hold points):** до закрытия — фото с рулеткой, исполнительная схема,
   испытания (опрессовка, залив, измерения электрика) → `/quality`. Без приёмки не закрывать.
5. **Конец дня:** `/log` — что сделано, сколько потрачено, остатки материалов; обновить задачи.
6. **Конец этапа:** `/quality` по чек-листу → вердикт → подтверждение → `set-stage N accepted`.
