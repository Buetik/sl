# Workflow: старт проекта и первичное обследование

## Шаг 1. Сбор исходных данных (последовательно, не всё сразу)
Анкета: `inputs/questionnaire.md`. Задавай вопросы блоками; уже известные — пропускай.

- **Блок A — контекст и правила:** 1) страна и город; 2) тип дома (панель/монолит/кирпич/
  монолит-кирпич, серия если известна) и год постройки; 3) площадь квартиры, этаж/этажность;
  4) собственность/новостройка (есть ли акт приёмки, гарантия застройщика).
- **Блок B — геометрия:** 5) план (БТИ/техпаспорт/застройщика — файл в `inputs/plans/`) и размеры
  помещений; 6) высота потолков (в нескольких точках); 7) фото текущего состояния каждого помещения
  (общий план + углы + стояки + щит + вентрешётки) → `inputs/photos/`.
- **Блок C — техническое состояние:** 8) состояние инженерии (проводка — алюминий/медь, наличие PE,
  щит, разрешённая мощность; трубы и стояки — материал, краны; отопление — тип, радиаторы;
  вентиляция; газ — есть/нет); 9) черновая отделка: бетон/штукатурка/стяжка есть или нет, «white box».
- **Блок D — желания и ресурсы:** 10) желаемый стиль, примеры; состав семьи, сценарии жизни;
  11) бюджет (общий и/или потолок) и сроки; 12) какие работы делает сам (опыт, свободное время в неделю,
  проживание в квартире во время ремонта) и какие готов поручить специалистам.

После каждого блока — записать в `knowledge/apartment.md` с маркировкой, обновить
`project/state.json → project.country/city`, `budget.json → user_budget`.

## Шаг 2. Лист замеров
Выдать перечень замеров (адаптировать под квартиру):
- Каждое помещение: длина/ширина по полу и под потолком, диагонали, высота в 4 углах и центре.
- Отклонение стен от вертикали (уровень 2 м / нивелир) по каждой стене в 2–3 точках.
- Перепады пола между помещениями (нивелир), отметки относительно входной двери.
- Проёмы: ширина/высота/толщина стены; окна: высота подоконника, размеры.
- Расположение и диаметры стояков, отсечных кранов, счётчиков, вентканалов (размер решётки, тяга),
  радиаторов (межосевое, тип подключения), электрощита (этажного и квартирного).
- Фото с рулеткой в кадре для всех инженерных узлов.

## Шаг 3. Совместное обследование (параллельно)
Вызвать через Agent tool одновременно: `interior-designer`, `construction-engineer`,
`electrical-engineer`, `plumbing-engineer`, `hvac-engineer`, `innovation-researcher` (только
фундаментальные возможности для этого типа дома), затем `project-manager` и `financial-controller`
(им нужны результаты первых), затем `quality-controller` (аудит пакета).

## Шаг 4. Результаты
1. Технический паспорт исходного состояния → `knowledge/apartment.md` (раздел «Технический паспорт»).
2. Перечень необходимых дополнительных замеров и обследований (в т.ч. специалистами).
3. Список потенциальных проблем → `knowledge/risks.md`.
4. Предварительная концепция ремонта → `knowledge/design-decisions.md` (ПРЕДЛОЖЕНО).
5. Предварительная оценка бюджета (диапазон, допущения явно) → `project/estimates/estimate-<дата>.md`.
6. Дорожная карта: адаптированная последовательность этапов → `project/stages/roadmap.md`;
   при изменении зависимостей — правка `project/state.json` и `reno.py validate`.
Этап 1 → `review`; приёмка этапа 1 — после подтверждения пользователем паспорта квартиры.
