# Workflow: пересмотр принятого решения

1. Найти решение в `knowledge/project-decisions.md` по ID; поставить статус ПЕРЕСМОТР (не удалять).
2. **Карта влияния:** какие решения ссылаются на это (поле «Связанные»), какие этапы его используют,
   что уже выполнено (state.json, журнал), что куплено (purchases.json).
3. **Параллельная оценка** всеми затронутыми агентами: что меняется в их системе.
4. **Анализ последствий** (таблица): переделки (объём, работы), деньги (возврат/продажа купленного,
   новые закупки, работа специалистов), сроки, риски, качество итогового результата.
5. Рекомендация: оставить / изменить / изменить частично. Не соглашаться автоматически — если
   пересмотр дорог и бесполезен, сказать прямо.
6. Явное решение пользователя → новая запись (ПРИНЯТО, «Заменяет: D-xxx»), старая → ОТМЕНЕНО
   («Заменено: D-yyy»); обновить профильные файлы, задачи, бюджет, при необходимости откатить статусы
   этапов (`reno.py set-stage N in_progress`).
