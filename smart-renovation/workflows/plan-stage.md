# Workflow: планирование этапа

1. **Ворота.** `reno.py gate N`. Закрыто → план можно готовить, но работы не начинать.
2. **Контекст.** Принятые решения, затрагивающие этап; выбранные материалы; ограничения из `apartment.md`.
3. **Технологии.** `innovation-researcher` — есть ли смысл в альтернативной технологии для этого этапа.
4. **План** (`project-manager`, шаблон `templates/stage-plan.md`): цель, задачи (≤ 1 дня каждая),
   зависимости, hold points (скрытые работы!), технологические перерывы, работы специалистов,
   критерии завершения.
5. **Материалы** (`materials-expert`) — для всего невыбранного; **инструменты** (`tools-expert`).
6. **Инструкции** — для ключевых операций (`/instruction`), можно отложить до начала работ.
7. **Бюджет этапа** (`financial-controller`) — позиции в budget.json.
8. **Чек-лист приёмки** (`quality-controller`) — до начала работ, чтобы пользователь знал критерии заранее.
9. **Согласование.** Всё, что требует решения пользователя, — списком; К1 — через `/decision`.
10. Сохранить, `reno.py set-stage N planned`, `reno.py validate`.
