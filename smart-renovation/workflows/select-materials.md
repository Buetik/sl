# Workflow: подбор материалов

1. **Требования** из технологии и условий: основание, помещение (мокрое/сухое, тёплый пол),
   толщины, нагрузки, класс (истираемость, PEI, класс ламината, огнестойкость), эстетика, бюджетный
   коридор, город (доступность).
2. **Совместимость с выбранной системой** (`knowledge/materials.md`).
3. **Исследование** — `materials-expert` по 14 критериям, ≥ 3 кандидата, анализ содержания отзывов,
   дата и ссылки, шаблон `templates/material-comparison.md`.
4. **Техническая проверка** — профильный инженер: подходит ли по техкарте к нашему основанию/условиям.
5. **Стоимость на объём объекта** — `financial-controller` (`reno.py calc ...`, `calc unit-price`).
6. **4 номинации** и рекомендация с учётом приоритетов: качество → долговечность → технологичность →
   эстетика → рациональная стоимость → простота самостоятельного монтажа.
7. **Выбор пользователя** → `/decision` → `knowledge/materials.md` (ПРИНЯТО) → позиция в
   `purchases.json` (planned) → бюджет.
8. Партийные материалы (плитка, ламинат, обои, колеровка) — заказывать единой партией с запасом.
