## Системы (совместимость)
<!-- Напр.: «Санузел: грунт X → гидроизоляция Y → клей Z → затирка W» -->
- **Потолок спален (ПРЕДЛОЖЕНО, D-001):** заделка рустов → анкер по типу плиты (для пустотных — допущенный для ПБ, в рёбра; [ПРОВЕРИТЬ]) → Виброфлекс-Коннект ПП / К15 (нагрузка ≤ 15 кг на подвес, сетка не реже 0,6×0,8 м) → CD 60×27 без касания стен → минвата без сжатия → 2×ГКЛ 12,5 вразбежку → Вибросил по периметру → сервисная зона (трассы к профилям) → натяжное полотно на стенах. Все компоненты акустической части — один производитель (Акустик Групп).
