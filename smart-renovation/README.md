# Smart Renovation AI

Мультиагентная система на Claude Code: персональное строительное бюро для самостоятельного ремонта
квартиры. 11 специализированных агентов, общая база знаний, ворота этапов, перекрёстная проверка
решений и детерминированные инженерные расчёты.

## Быстрый старт

1. Откройте Claude Code **в корне репозитория** (локально: `cd sl && claude`; в облаке — сессия на этом репозитории).
2. Введите `/renovation-start` и отвечайте на вопросы блоками.
3. Планы, фото и документы кладите в `smart-renovation/inputs/{plans,photos,documents}/` или присылайте в чат.

Субагенты и команды загружаются при старте сессии: после их изменения откройте новую сессию.

## Архитектура

```
Пользователь ──► команды (/next, /materials, …) ──► главная сессия = диспетчер прораба
                                                        │  вызывает субагентов (параллельно/цепочкой)
                                                        │  по матрице workflows/cross-review.md
            ┌──────────────┬──────────────┬─────────────┼──────────────┬──────────────┐
      project-manager  interior-designer  construction  electrical  plumbing  hvac  …
            └──────────────┴── пишут черновики, заключения ──┴──────────────┴──────────────┘
                                                        ▼
                  knowledge/ (нарратив, решения)   project/ (JSON: этапы, задачи, смета, закупки)
                                                        ▲
                                        tools/reno.py — ворота этапов, валидация, расчёты
```

Почему так:
- **Субагенты Claude Code** (`.claude/agents/`) дают каждой роли свой системный промпт, набор
  инструментов и чистый контекст. Субагенты не вызывают друг друга, поэтому оркестрацию выполняет
  главная сессия по явной матрице взаимодействия — это прозрачно и проверяемо.
- **Файловая база знаний** — общая память всех агентов между сессиями; в git видна история каждого решения.
- **JSON + Python (stdlib)** для состояния и арифметики — LLM не считает объёмы «в уме», а
  ворота этапов нельзя «уговорить»: `set-stage accepted` без чек-листа и подтверждения пользователя
  отклоняется скриптом.
- MCP-серверы не нужны: веб-поиск (WebSearch/WebFetch) встроен в Claude Code.

## Агенты (`.claude/agents/`)

| Агент | Роль |
|---|---|
| `project-manager` | Главный прораб: последовательность, календарь, зависимости, ворота этапов, задачи |
| `interior-designer` | Архитектор-дизайнер: планировка, эргономика, концепция, свет, хранение |
| `construction-engineer` | Строительные технологии и отделка, технологические карты |
| `electrical-engineer` | Электрика, щит, защита, освещение, умный дом, слаботочка |
| `plumbing-engineer` | Водоснабжение, канализация, трапы, инсталляции, защита от протечек |
| `hvac-engineer` | Отопление, тёплые полы, вентиляция, кондиционирование, микроклимат |
| `materials-expert` | Исследование рынка, ≥ 3 варианта, 14 критериев, анализ отзывов, 4 номинации |
| `tools-expert` | Инструмент: купить / арендовать / заменить |
| `innovation-researcher` | Новые технологии с оценкой реальной пользы |
| `quality-controller` | Независимый технадзор: чек-листы, приёмка, аудит |
| `financial-controller` | Смета, план/факт/прогноз, резерв, поставщики |

## Команды (`.claude/commands/`)

| Команда | Что делает |
|---|---|
| `/renovation-start` | Старт: анкета из 12 вопросов → совместное обследование → паспорт, риски, концепция, бюджет, дорожная карта |
| `/apartment-analysis [помещение]` | Анализ планировки, фото и состояния |
| `/design <задача>` | Дизайн-решения с проверкой реализуемости |
| `/plan-stage [N]` | План этапа: задачи, материалы, инструмент, бюджет, чек-лист |
| `/materials <категория>` | Подбор материалов с исследованием рынка |
| `/compare <A> vs <B>` | Сравнение товаров или технологий |
| `/innovation [тема]` | Новые технологии для этапа |
| `/instruction <работа>` | Технологическая инструкция из 19 разделов |
| `/estimate [этап]` | Смета, учёт фактических затрат |
| `/tools [этап]` | Подбор инструмента |
| `/quality <этап>` | Проверка качества и приёмка этапа |
| `/next [горизонт]` | Что делать сегодня / на неделе |
| `/project-status` | Общий статус |
| `/decision <решение>` | Зафиксировать или пересмотреть решение |
| `/risks [тема]` | Реестр рисков |
| `/audit [область]` | Независимый аудит проекта |
| `/log <событие>` | Журнал работ, трат, дефектов |

`/plan`, `/status` и `/review` — встроенные команды Claude Code, поэтому их аналоги названы
`/plan-stage`, `/project-status` и `/audit`.

## Структура

```
CLAUDE.md                     # корневой: подключает smart-renovation/CLAUDE.md
.claude/agents/               # 11 агентов
.claude/commands/             # 17 команд
smart-renovation/
  CLAUDE.md                   # правила системы: маркировка, решения, ворота, красные линии
  knowledge/                  # общая база знаний
    apartment.md              # паспорт квартиры
    project-decisions.md      # реестр решений (источник истины)
    design-decisions.md  engineering.md  materials.md  technologies.md
    safety-and-regulations.md # нормы, ограничения, красные линии
    stage-catalog.md          # 24 этапа: ответственные, зависимости, контрольные точки
    risks.md
  project/
    state.json                # статусы этапов и зависимости
    tasks/tasks.json  estimates/budget.json  purchases/purchases.json
    stages/  instructions/  specifications/  quality-checklists/  reviews/  log/journal.md
  templates/                  # инструкция (19 разд.), сравнение (14 крит.), спецификация,
                              # чек-лист, смета, решение, план этапа, заключение, разногласие
  workflows/                  # start-project, plan-stage, select-materials, execute-work,
                              # quality-control, change-decision, cross-review (матрица агентов)
  research/{materials,technologies,innovations,tools}/
  inputs/{plans,photos,documents}/  questionnaire.md
  tools/reno.py               # состояние, ворота этапов, бюджет, валидация, калькуляторы
  tools/tests/test_reno.py
```

## Утилита `reno.py`

```bash
python3 smart-renovation/tools/reno.py status
```

```bash
python3 smart-renovation/tools/reno.py next
```

```bash
python3 smart-renovation/tools/reno.py gate 15
```

```bash
python3 smart-renovation/tools/reno.py budget --recalc
```

```bash
python3 smart-renovation/tools/reno.py calc mix --area 20 --thickness-mm 15 --consumption 0.9 --bag-kg 30
```

Расчёты: `mix` (сухие смеси), `tile`, `paint`, `sheet` (ГКЛ), `linear` (погонаж), `slope` (уклоны),
`voltage-drop`, `unit-price`, `room` (площади помещения), `power` (нагрузки и расчётный ток),
`expr` (любая формула, безопасное вычисление без eval). Тесты:

```bash
python3 -m unittest discover -s smart-renovation/tools/tests -v
```

## Правила, которые система соблюдает

- Маркировка достоверности: `[ФАКТ] [НОРМА] [ПРОИЗВОДИТЕЛЬ] [ПРАКТИКА] [ПРЕДПОЛОЖЕНИЕ] [ПРОВЕРИТЬ]`.
- Без выдуманных норм, цен, рейтингов и отзывов; у исследований есть дата и ссылки.
- Решение получает статус ПРИНЯТО только после вашего явного подтверждения; критические (К1) — после перекрёстной проверки.
- Этап не начинается, пока зависимости не приняты по чек-листу.
- Красные линии: работы под напряжением, газ, несущие конструкции, общедомовые стояки, тёплый пол от центрального отопления — никаких инструкций «сделай сам».
- Система не соглашается автоматически: на неверное решение — объяснение и альтернатива.

## Ограничения и что можно подключить

- **Веб-поиск** — встроенные WebSearch/WebFetch. Маркетплейсы часто не отдают отзывы роботам;
  агент тогда пишет «нет данных», а не придумывает.
- **Работа с изображениями** — Claude читает фото и планы, но размеры по фото — только оценка; нужны замеры.
- **Нормативы** — встроенной базы норм нет; агенты ссылаются на документы и помечают пункты для сверки.

Возможные расширения (при реальной необходимости):
1. MCP для таблиц (Google Sheets) — смета в привычном виде для совместного доступа.
2. MCP браузера (Playwright) — надёжнее читать карточки и отзывы маркетплейсов.
3. Хук на `SessionStart`, выводящий `reno.py status` при каждом запуске.
4. Генерация планов и схем в SVG/DXF из `apartment.md` (отдельный инструмент).
5. Новые агенты (например, отдельный специалист по гидроизоляции или по мебели на заказ) — см. раздел 12 `CLAUDE.md`.
