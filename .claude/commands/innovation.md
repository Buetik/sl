---
description: Найти современные технологии для текущего (или указанного) этапа и оценить их реальную пользу
argument-hint: "[тема или номер этапа]"
---
Тема: $ARGUMENTS (если пусто — текущий этап из `reno.py status`).

1. Прочитай `smart-renovation/knowledge/technologies.md` и `research/innovations/` — не повторяй исследованное.
2. Вызови `innovation-researcher` с контекстом объекта (тип дома, состояние, что делает пользователь сам).
3. По каждой рекомендованной технологии вызови `construction-engineer` (или профильного инженера) для проверки применимости и `financial-controller` для оценки стоимости — параллельно.
4. Покажи таблицу «Рекомендую / Можно рассмотреть / Не рекомендую» с причинами. Принятие — через `/decision`.
