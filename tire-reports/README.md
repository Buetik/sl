# Агенты подбора шин

Команда Claude Code агентов, которая разбирается в шинах, анализирует отзывы и подбирает лучшие варианты по соотношению цена/качество.

| Агент | Роль |
|---|---|
| `tire-spec-researcher` | Характеристики, EU-маркировка, независимые тесты (ADAC, Auto Bild, «За рулём», Tyre Reviews и др.), список кандидатов |
| `tire-review-analyst` | Отзывы владельцев (Яндекс Маркет, Drom, Drive2, Ozon и др.), фильтрация накруток, частые дефекты |
| `tire-price-scout` | Актуальные цены у 3–5 продавцов, наличие, дата производства, акции |
| `tire-value-advisor` | Итоговый рейтинг: качество (тесты 60% + отзывы 40%), индекс цена/качество, рекомендация |

Файлы: `.claude/agents/*.md` и `.claude/skills/tire-advisor/SKILL.md`.

## Как пользоваться

```
/tire-advisor 205/55 R16 зима шип, Kia Rio, бюджет до 40000 ₽, езжу в основном по городу
```

Или просто напишите в чате: «Подбери летние шины 225/45 R17 для Skoda Octavia, важна тишина».

Можно вызвать агента отдельно: «Используй tire-review-analyst и проанализируй отзывы о Nokian Hakkapeliitta 10p».

Отчёты сохраняются в эту папку.
